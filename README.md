## 📖 Descripción del Proyecto

**El Guerrero del Camino** es un panel de gestión de viajes desarrollado para una agencia de viajes que permite a los usuarios:

- Sincronizar automáticamente reservas de vuelos, hoteles y alquiler de vehículos
- Visualizar itinerarios completos consolidados por viaje
- Gestionar reservas manuales y automáticas
- Convertir precios en tiempo real a cualquier moneda del mundo
- Aplicar reglas automáticas de penalización/descuento en alquiler de vehículos
- Ver saldo de puntos/millas y su aplicación en reservas

El producto está pensado para más de **10,000 usuarios** y soporta integraciones con múltiples proveedores internacionales.

## 🎯 Características Principales (MVP)

- Autenticación de usuarios
- Sincronización automática de reservas (vuelos • hoteles • autos)
- Dashboard responsive (mobile + desktop)
- Agrupación de reservas por viaje
- Resumen visual cronológico de itinerario completo
- Conversor de monedas integrado (cualquier moneda mundial)
- Módulo de alquiler de vehículos con reglas automáticas:
  - +15% penalización por devolución tardía
  - -10% descuento por devolución a tiempo o anticipada
- Visualización de saldo de puntos/millas
- Optimización de menú y experiencia de usuario
